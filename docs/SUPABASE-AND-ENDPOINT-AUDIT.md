### 2.2 Redundant Middleware Identified & Remediated

1. **`dashboardGate` vs `requireDashboardAuth` in `brain-server/index.mjs` (Consolidated):**
   - **Finding:** `dashboardGate` and `requireDashboardAuth` duplicated identical query-token migration (`isDashboardHtmlRoute`, `checkAuthRateLimit`, `tryMigrateQueryToken`) and `verifyDashboardAccess(req)` checks.
   - **Action Taken:** Consolidated `dashboardGate` to alias `requireDashboardAuth`, which already branches cleanly between HTML (`isDashboardHtmlRoute(req) || wantsHtml(req)`) and JSON (`401` JSON response).
2. **Unused Handler `brain-server/stripe-ingest.mjs` Standalone Route vs `dispatchStripeWebhook`:**
   - **Finding:** `handleInternalStripeConversion` in `brain-server/stripe-ingest.mjs` is invoked by `dispatchStripeWebhook` when `POST /api/v1/stripe/webhook` is called without a `stripe-signature` header. It is active and tested, so it must be retained.
3. **Module-Init Env Freezing in `brain-server/dashboard-auth.mjs` (Fixed):**
   - **Finding:** `DASHBOARD_VIEW_TOKEN` was read once at module load time (`const DASHBOARD_VIEW_TOKEN = process.env...`), preventing runtime/test environment updates from taking effect if `dotenv` or test harnesses populated env vars after import.
   - **Action Taken:** Refactored to `getDashboardViewToken()` so token resolution is always current.
