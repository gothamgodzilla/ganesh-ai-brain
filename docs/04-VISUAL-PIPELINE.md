# Visual Production Pipeline (Gamma + Napkin)

## Gamma.app (connected)
- Investor decks, countdown pages, ecosystem maps, roadmaps
- Use for high-level narrative and polished slides
- Search existing: “GANESH Ecosystem”, “Ganesh AI Festival Power Hub”

## Napkin.ai (manual / API)
- Turn any text block into editable diagrams, flowcharts, mind maps, data charts
- Perfect for architecture diagrams of this very state machine
- Export SVG / PPT / PNG and drop into Gamma or docs

## Workflow
1. Main agent produces structured text (architecture, 3 features, Nemesis plan)
2. Pipe text → Napkin for diagrams
3. Pipe summary + diagrams → Gamma for final deck or landing
4. Store links in Memory region
