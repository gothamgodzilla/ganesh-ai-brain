# MCP Servers & Sub-Agent Architecture

## Primary MCP

- **Playwright MCP** (`@playwright/mcp`) — preferred for research, snapshot-based interaction, and live testing.
- Custom MCP workers generated by the build for:
  - Telephony / early-media simulation
  - Privacy & key management
  - QCN simulation
  - State-machine inspection

## Sub-Agent Pattern (SuperClaude style)

- Architect Agent → formalizes hierarchical machines
- Math / Invariant Agent → checks privacy, fidelity, safety
- Quantum Specialist Agent → QCN layer
- Implementation Agents → code + MCP stubs
- Monitor Agent → dashboard + health

All sub-agents operate inside the legal event set of the current State Frame.

## Integration Notes

- Claude Code is the primary host for MCP + sub-agents in the current workflow.
- Grok can generate prompts, structure, and push knowledge into this brain, but does not directly drive local Playwright MCP.
