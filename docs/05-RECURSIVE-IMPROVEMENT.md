# Recursive Self-Improvement Loops

Inspired by modern RSI research (Recursive Superintelligence patterns):

1. After every successful `Responding` state, log:
   - What worked
   - What was slow / expensive
   - Which subagent returned the highest value
2. Periodic “meta” cycle (daily / weekly automation):
   - FeatureEvaluator scores possible self-improvements
   - NemesisBuilder can be pointed at Ganesh’s own public surface
   - Safety proposes tighter guards
3. Human-in-the-loop approval before any self-modification of the machine definition or prompts
4. Version the machine + prompts in this repo; every improvement is a commit

This turns Ganesh into a system that gets better at getting better.
