# Standard Workflows

## 1. Content for Monetization
`INPUT` → Understanding → DELEGATE ContentMonetizationAgent → format → Gamma deck or Napkin visuals → Memory

## 2. Evaluate 3 New Features
`INPUT` with feature list → DELEGATE FeatureEvaluatorAgent → ranked table (productivity / revenue / popularity / effort) → decision gate

## 3. Nemesis / Competitive Analysis
Paste public URL → DELEGATE NemesisBuilderAgent →
- Extract public structure & mission
- Identify 3 high-level structural / product weaknesses
- Produce differentiated “Nemesis” concept that keeps mission, improves stability & retention, adds original twist
- Never copy code/assets/text

## 4. Full Second-Brain Cycle
Any request runs Main + Safety + Memory in parallel. Subagents only when needed. Visuals produced on demand. Insights written back for the next recursive loop.
