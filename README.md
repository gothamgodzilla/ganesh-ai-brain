# Ganesh AI Brain (Second Brain)

**Hierarchical + Parallel State Machine • SuperClaude-style Subagents • MCP Server Ready • Gamma + Napkin Visual Pipeline • Recursive Self-Improvement Loops**

This repository is the living second brain for the entire Ganesh ecosystem (Ganesh.Guru, COEXIST, LynxLogix, Mangasm, business engines, etc.).

It teaches and operationalizes:
- Advanced XState hierarchical + parallel orchestration
- Sub-agent delegation (Content Monetization, Feature Evaluator, Nemesis Builder, Safety, Memory)
- MCP server integration points
- Visual production workflows with Gamma.app and Napkin.ai
- Recursive self-improvement patterns inspired by modern RSI research

## Quick Start

```bash
npm install xstate
# then load the machine + orchestrator
```

See `/docs` and `/src` for the full package.

## Core Philosophy
Ganesh is not a single agent. It is a parallel organism:
- Main flow handles the request
- Safety watches continuously
- Memory updates in parallel
- Specialist subagents are spawned on demand
- Visual tools (Gamma / Napkin) produce investor-ready and product assets
- Recursive loops improve the system itself over time
